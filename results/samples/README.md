# Listening samples (RAVEL-Tiny after Stage 1: 400 CPU training steps)

Each `*_ravel_continuation.wav` = 1.2 s of a REAL held-out speaker (prompt, fed as RAVEL's own past output)
followed by 4 s generated by RAVEL through the full streaming path. `*_real_codec_reference.wav` = the real
continuation passed through the same frozen EnCodec (what the codec alone sounds like). `3_from_silence_ravel.wav`
= 4 s generated with no prompt.

* top level: temperature 0.8, top-k 50. Output collapses to near silence (1–14% of 20 ms frames above -40 dBFS,
  vs ~70% for real speech).
* `temperature_1.0/`: temperature 1.0, no top-k. Energetic output (72–84% active frames), expected to be speech-like
  babble with no words; not verified by ear or ASR.

Spoken-digit task answers (the only case with recognisable words) are in `../digit_qa_policy_examples/`
(stereo: left = user question, right = RAVEL's answer). Regenerate: `python scripts/generate_samples.py`.
